# BTB Insurance Client Management System

## Overview
A web-based system for managing insurance client records digitally.

## Features
- 🔐 Secure admin login
- ➕ Add new clients
- 📋 View all clients
- ✏️ Edit client information
- 🗑️ Delete clients
- 🔍 Search by name, phone, or policy
- 📊 Dashboard with statistics
- ⏰ Policy expiry tracking

## Technology Stack
- **Frontend**: HTML, CSS, JavaScript
- **Backend**: PHP 7.4+
- **Database**: MySQL 5.7+
- **Server**: Apache (XAMPP)

## Installation
1. Copy folder to `htdocs`
2. Import database from `database.sql`
3. Update `config/database.php` if needed
4. Access via `http://localhost/btb_crm`
